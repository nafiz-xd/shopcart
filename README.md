# ShopCart 🛒

A demo **online shop** with a real shopping-cart experience — no backend, everything runs in the browser.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/shopcart/

## ✨ Smart Features
- **Live search, category filter & sorting** (price, rating, popularity)
- **Wishlist** — tap ❤️ to save favourites and view them with one filter
- **Cart drawer** — add/remove items, change quantities, totals update instantly
- **Promo codes** — try `NAFIZ10` for 10% off
- **Smart delivery** — ৳60 delivery, **FREE** on orders over ৳1,000
- **Checkout flow** — delivery form, payment options (Cash on Delivery / bKash / Nagad) and an order-confirmation screen with order ID
- **Persistent cart & wishlist** — saved in your browser (localStorage), so they survive a page refresh

## 🛠️ Tech
HTML • CSS • JavaScript • localStorage — single page, hosted on GitHub Pages. Demo only — no real orders are placed.
